# Signal Ledger V3 — Screenshot Critic Round 1

> Review mode: screenshot-only manual critic. The harness available in this session has no independent subagent context, so this is explicitly not represented as an independent model review. Source/CSS/history were excluded from the visual judgement itself.

## Visual-language diagnosis

The no-top-navigation version finally reads as an editorial knowledge instrument rather than a publication navbar wrapped around a landing page. The Signal Rail gives the page a coherent orientation grammar, and the warm paper / graphite / vermilion system is restrained enough to avoid SaaS-card aesthetics. The main weakness is scale hierarchy: several display elements still compete too aggressively with reading content.

## 3 serious problems

1. **Homepage opening title dominates too much of the first screen.** The idea is strong, but the scale makes the page feel like a poster before it feels like a writing index.
2. **Article opening hierarchy is oversized relative to the reading system.** The H1 consumes too much vertical attention before the actual article begins.
3. **Context utilities are too weak or too tool-like.** The right-side Search/Theme treatment reads like a miniature navigation list, while the article TOC is so small that it becomes annotation rather than usable orientation.

## 3 strengths

1. The Signal Rail is a real visual signature and consistently encodes index / chronology / reading state without adding decorative graphics.
2. The page has no cards, gradients, shadows, pill clouds, or second signature motif; the visual language is materially more editorial than the retired Research Folio composition.
3. Mobile structure preserves the same information hierarchy without keeping desktop side rails, which is directionally correct for the brief.

## 5 next actions

1. Reduce the homepage opening H1 and keep its measure bounded.
2. Balance ledger-entry Chinese title wrapping to avoid awkward orphan fragments.
3. Reduce desktop article H1 scale and align it more tightly with the reading axis.
4. Increase TOC legibility while keeping it visually subordinate.
5. Tighten Search overlay vertical rhythm so it feels like a document index, not a modal product surface.

## Accepted changes

All five actions were accepted because they refine the existing Signal Rail / editorial system and do not introduce a second visual signature.

## Score

**6.0 / 10** — direction is correct and distinctive enough to continue, but hierarchy and reading calibration are not yet stable.
